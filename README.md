# Token Generator (Vanilla JS)

Bu proje, tamamen **tarayıcı üzerinde çalışan basit bir rastgele token üreticisidir**.  
Kullanıcı tarafından belirlenen uzunlukta, karışık karakterlerden oluşan token üretir.

## 🚀 Özellikler

- Kullanıcıdan token uzunluğu alma
- Harf, sayı ve özel karakter kombinasyonu
- Rastgele ve karışık token üretimi
- Tek tıkla üretim
- Tamamen frontend (HTML + CSS + JavaScript)

## 🧠 Nasıl Çalışır?

Uygulama üç farklı karakter havuzu kullanır:

- Harfler (a-z, Türkçe karakterler dahil)
- Sayılar (0-9)
- Özel karakterler (!, ?, *, -, vb.)

Her karakter üretiminde:
- Rastgele bir kategori seçilir
- O kategoriden rastgele bir karakter alınır
- Belirlenen uzunluk kadar tekrar edilir
